# CONTRIBUTING

Thanks for helping out!

Check the [Contributing Guide](https://docs.projectbluefin.io/contributing) for contribution information.

This repository builds the images. The configuration files that Bluefin used to pull from [@projectbluefin/common](https://github.com/projectbluefin/common) now live in `system_files/shared/` here (see `NOTICE.common`), so change them in this repository. Make sure you check [the architecture diagram](https://docs.projectbluefin.io/contributing#understanding-bluefins-architecture).
